# US Market Briefing

**미국 증시가 지금 어떤 상태인지, 숫자 기준으로 판정해 채팅으로 브리핑한다.**

"조정장 진입" 같은 말은 대부분 누가 선언하는 게 아니라, 시장 관례로 정해진 숫자 기준을 넘었을 때 붙는 이름이다.
같은 기준을 코드로 계산해 뉴스를 기다리지 않고 상태를 확인하고, 위기 때 저가 매수용 실탄을 언제 쓸지 미리 정한 규칙으로 판단한다.

개인용이라 웹사이트 대신 Claude 채팅으로 받는다. 브리핑을 보다가 그 자리에서 바로 질문할 수 있다.

## 구조

```
GitHub Actions (미국 장 마감 뒤 매 거래일)        Claude 예약 작업 (주기는 자유)
  Yahoo Finance · FRED에서 받기                     data/ 읽기
  지표 계산 · 상태 판정                    →         채팅으로 브리핑 (표·차트)
  data/에 JSON 커밋                                 그 세션에서 바로 질문
```

- **판정은 Actions가 확정한다.** 같은 숫자면 언제나 같은 판정이 나온다. Claude는 이미 정해진 판정을 설명만 한다.
- **브리핑 주기를 바꿔도 된다.** 계산은 매 거래일 따로 돌고, 브리핑은 언제 열든 최신 값과 최근 20거래일의 변화 목록을 보여 준다.
- **판정은 매번 전체 이력에서 다시 계산한다.** 하루를 빠뜨리거나 기준을 바꿔도 결과가 꼬이지 않는다.

## 판정 기준

| 상태 | 조건 | 성격 |
|---|---|---|
| 약세장 | 사이클 고점 대비 -20% 이하. 저점 대비 +20% 반등해야 해제 | 관례 |
| 조정장 | 사이클 고점 대비 -10% 이하. -8%보다 얕아지면 해제 | 관례 (해제 여유폭은 자체) |
| 경계 | 200일선 아래 3거래일 연속, VIX 25 이상, 50일선이 200일선 아래 중 하나. 모두 풀린 날이 3일 연속이면 해제 | 자체 |
| 정상 | 위에 해당 없음 | |

사이클 고점은 평소엔 사상 최고 종가이고, 약세장이 끝나면 그 저점 이후의 최고 종가로 새로 시작한다
(2023년 가을처럼 사상 최고치 아래에서도 조정장이 정의되는 관례를 따른다).
실탄 단계는 사상 최고 종가 대비 -20%, -30%, -40%. 모든 값은 [`config/rules.yaml`](config/rules.yaml)에서 바꾼다.

## 데이터

| 지표 | 출처 | 비고 |
|---|---|---|
| S&P 500 일별 시가·고가·저가·종가 (전체 이력) | Yahoo Finance, 실패 시 Stooq | 비공식 |
| VIX | Yahoo Finance, 실패 시 CBOE | |
| 달러 인덱스 (DXY) | Yahoo Finance | 비공식 |
| 미 10년물·2년물 금리, 10년-2년 금리차 | FRED (DGS10, DGS2, T10Y2Y) | 공식, 키 불필요, 하루 늦게 발표 |
| 하이일드 스프레드 | FRED (BAMLH0A0HYM2) | |

출처 하나가 실패해도 나머지는 계산하고, 실패한 지표는 직전 값을 날짜와 함께 "stale"로 표시한다.
지수 종가를 못 받으면 아무것도 덮어쓰지 않고 `data/status.json`에 실패를 남긴다.

## 파일

```
config/rules.yaml      판정 기준
scripts/compute.py     수집 → 계산 → data/ 쓰기
scripts/sources.py     출처별 수집·해석
scripts/indicators.py  이동평균, MACD, RSI, ADX
scripts/state.py       상태 판정, 상태 변화 이력, 하락 구간
data/latest.json       최신 브리핑 데이터
data/recent.json       최근 260거래일 (차트용)
data/events.json       1990년 이후 상태 변화
data/episodes.json     2000년 이후 조정·약세 구간
data/daily/            날짜별 스냅샷
docs/briefing.md       Claude 예약 작업이 따르는 브리핑 지침
```

## 로컬 실행

```bash
pip install -r requirements.txt
python -m pytest -q
python scripts/compute.py
```

투자 조언이 아니다. 지표는 대부분 후행 지표라 이미 일어난 일을 확인할 뿐 다음 움직임을 예측하지 않는다.
